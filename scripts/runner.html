🧪 Qwest — Runner de tests

Lance les scripts de vérification depuis le navigateur. Crée un fichier de log horodaté dans scripts/logs/ à donner pour analyse.

📖 Quand lancer chaque test ? (clique pour ouvrir)
  1. Crée une partie de test dans l'interface prof avec un quiz d'au moins 8 questions si tu veux utiliser « Tout lancer ». Pour un seul script à la fois, 1-2 questions suffisent.
  2. Note le code de partie ici → Code de partie. NE clique pas encore « Lancer la partie ».
  3. 🟢 check_server — n'importe quand.
  4. 🟡 race_test — sur une partie créée mais pas encore lancée. Le script s'occupe du démarrage.
  5. 🟢 chaos_test — autonome : crée SA PROPRE session, simule une classe de collège (double connexion, vol de pseudo, élève très lent, coupure réseau de 45 s, spam de réponses, recherche de triche dans les payloads, réponse dernière seconde), mesure la synchro d'affichage et vérifie le score de CHAQUE élève au point près, puis nettoie. Durée ≈ 2-3 min.
  6. 🔴 idempotence_test et load_test — la partie doit être en cours (state=playing, Q0 ou plus). Après race_test, c'est déjà le cas. load_test avance maintenant automatiquement à la question suivante si la précédente est terminée (option auto-prep).

💡 Si tu as déjà cliqué « Lancer la partie » : les scripts fonctionnent quand même grâce à l'idempotence côté serveur. Tu peux lancer tous les tests sauf check_server qui n'a pas besoin de partie.

Enchaîne les 9 tests : check_server → race_test → idempotence_test → load_test (stable, last-second, slow, oscillating, interrupt) → load_test 30 élèves.
Durée ≈ 30 s × race + 6 × durée load_test. Avec durée=30 s : ~4 min. Avec durée=60 s : ~7 min.
