Qwest — Test multi-onglets (NAT honnête)

Ouvre N vraies fenêtres index.html qui jouent comme de vrais élèves, depuis cette unique IP source. Reproduit la condition NAT du collège.
Mode d'emploi :
  • Crée d'abord une partie depuis l'interface prof, note le playCode, et démarre la partie quand tous les onglets sont prêts.
  • Autorise les popups dans ton navigateur pour ce site (sinon ouvre un par un).
  • Garde dashboard.html ouvert dans un autre onglet pour mesurer le vrai volume serveur en temps réel.
  • Pour fermer tous les onglets d'un coup : bouton « Tout fermer » ci-dessous.
